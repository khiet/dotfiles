# Check your understanding

Use one placement, or both when each serves a distinct purpose:

- **Early prediction**: for a surprising behavior. Place one short question before **Summary: how it works** and resolve it explicitly within that section.
- **Final application**: for a likely misconception. Add a last section after the Scope check with a prediction on a fresh input or boundary case. Keep the question visible; put the answer, its causal explanation, and its locator inside `<details>` so the reader can attempt it first.

Use free response unless multiple-choice alternatives expose meaningful misconceptions.

Done when every question has an answer that explains its outcome and cites a locator.
