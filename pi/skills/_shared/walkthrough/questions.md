# Check your understanding

Use one placement, or both when each serves a distinct purpose:

- **Early prediction**: for a surprising behavior. Place one short question after the representative input is introduced and before the first causal step, and resolve it explicitly in the step that settles it.
- **Final application**: for a likely misconception. Add a last section, after every other, with a prediction on a fresh input or boundary case whose outcome the page has not stated; when the page must state the likeliest misconception's outcome elsewhere, as a failure mode, ask about another input the same mechanism decides. Keep the question visible; put the answer, its causal explanation, and its locator inside `<details>` so the reader can attempt it first.

Use free response unless multiple-choice alternatives expose meaningful misconceptions.

Done when every question has an answer that explains its outcome and cites a locator.
